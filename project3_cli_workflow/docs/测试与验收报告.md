## 7. 已知问题

当前状态（2026-11-01）：

1. 项目一 PDF 本地推理使用 PaddlePaddle CPU 版；`local_gpu` 是模式标签，实际设备为 `cpu`。PP-StructureV3 初始化已设置 `enable_mkldnn=False`，用于规避原 PIR/MKLDNN 错误；混合验收和 134 项回归测试均通过。关闭 MKLDNN 后 CPU 推理速度较慢。
2. 项目一完整 pytest：134/134 通过（完整套件 132 passed + 2 skipped，随后补跑 2 个受环境变量控制的真实 Paddle 测试，2 passed）。
3. 项目二只实现规则审核：数学表达式校验、保守错别字词典、定位与批注；不是完整 AI 智能审核。
4. `complete_success=True` 不代表数据合规。
5. `unverified` 不是错误，只表示没有可验证的明确计算表达式。
6. `manual_review` 不是已确认错误。
7. 项目一、项目二没有配置 Ruff，因此未执行这两个项目的 Ruff 检查；项目三 Ruff 检查通过。
8. 隔离的部分成功故障注入任务中曾观察到一次瞬态 `WinError 5` 交付目录重命名失败，`resume` 后恢复成功，重跑未复现。
9. 本文档部分历史内容尚未同步；已在文首增加状态说明，并以根目录当前报告为准。
